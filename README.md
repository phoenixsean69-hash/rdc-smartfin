# Smart District — RDC Council Web UI (Static Prototype V5)

A static React + TypeScript + Vite prototype of the Rural District Council client for Smart District / RDC SmartFinance AI.

## Included UI modules

- Dashboard
- Revenue
- Payments
- Budgets
- Expenditure
- Residents
- SMS Automation
- AI Insights
- Reports
- Settings

## SMS Automation prototype

The SMS module includes:

- resident SMS reachability counters
- repetitive / automated SMS rules
- automatic resident account alerts
- scheduled messages
- recent delivery logs
- quick broadcast composer
- static delivery-health metrics
- local UI toggles for pausing/activating automation rules
- demo send feedback (no real SMS is sent)

All data is static. No backend, live AI model, payment provider or SMS gateway is connected yet.

## Run

```bash
npm install
npm run dev
```
